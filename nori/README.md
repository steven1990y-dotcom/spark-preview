| spec.html | 设计规范长页（另链） |
| app-shell.js / app-shell.css | 真路由壳、隐藏画廊、设置内演示态 |
| v1.2.js / v1.2.css | 已验收 v1.2 交互 |
| nori-v5/ | 情绪 SVG |
