最终方向：**A「星火准星」**。中心四芒星表示星火，四段圆轨道表示行星与远征，轴向缺口将它们连接到产品的锁定准星。24px 时星芒和轨道仍有清晰间隙；16px 时保留整体轮廓与四向节奏。B 的火种与轨道在小尺寸下容易合并，C 的角框更偏向操作图标，因此采用 A。

## 几何构造

- 采用 64 × 64 网格，中心 (32, 32)，以 4 单位为基本节奏。最终开环中心线半径 24，描边 5，圆端帽半径 2.5。每象限从 12° 到 78°，留下 24° 的轴向缺口；缺口内不添加细刻度。
- 星芒由内凹三次 Bézier 侧边与二次曲线尖端组成。四个尖端做约 1 单位的光学圆角，星芒可见跨度约 32.5 单位。中心保持实心，保证缩小后的识别度。
- A 只有两个路径元素；开环的四段为一个路径的四个独立子路径。B 最细描边 4 单位，C 为 5 单位。最终 5 单位描边在 24px 时为 1.875px，在 16px 时为 1.25px。
- 审阅精修（v5.4）：最终图标在右上 45° 的轨道上加一颗蓝紫行星（#8F7BFF，r=3.9），该段轨道在行星两侧各断开约 20°，保证 24px 时行星与轨道之间仍有约 0.8px 间隙；单色版行星与轨道同色。B、C 草案各只出现一枚紫色行星。产品的外刻度环、内四弧、外十字刻度和四角框是场景语言，图标只提炼其中的轴向开环与星芒，避免堆叠细节。
- 双语组合以图标画布高度 H = 64 为基准：图标后间距 0.33H = 21.12；中文可见高度 0.5H = 32；英文可见高度 0.16H = 10.24；两行间距 0.1H = 6.4。文字块总高 48.64，在图标上垂直居中，两行按可见左边缘对齐。英文保留自然字宽，不拉伸；其右边缘略长于中文。中文单行组合垂直居中。

## 字体与路径

中文来源：`/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`，通过 fontTools `TTCollection` 选择 **Noto Sans CJK SC / Bold**，不是 JP 默认面。字距为 **+0.04em**（40 字体单位），仅加在字间，不留末尾追踪空白。用 `SVGPathPen` 提取字形；「火」的两个独立侧点轮廓被移除并替换为两枚琥珀色实心菱形，主体轮廓保持原样。

英文来源：`/usr/share/fonts/truetype/sand-box/google/Inter/Inter-VariableFont_opsz,wght.ttf`，实例化 **Inter SemiBold，wght=600，opsz=14**。文案 `SPARK EXPEDITION`，追踪 **+0.18em**，保留原字体单词空格，不添加首尾追踪空白。不进行横向缩放。

两个字标均将实际可见字形高度归一到 100，`viewBox` 紧贴字形边界，无字体行高或 em 框留白。中文无拉丁 cap height，使用完整汉字可见高度；英文使用实际大写高度。字形全部为路径，无 `<text>`、字体加载或外部引用。

## 留白与尺寸

最小保护区：标志四周至少 **0.25 × 图标高度 H**。64px 图标四周至少 16px；组合标志也以其中的图标高度计算。SVG 内部画布留白不代替使用时的外部保护区。

最小图标尺寸 **16px**，优先使用 **24px 或更大**。完整组合最小宽度 **96px**，但双语组合在该宽度下英文只有约 3.9px 高，属于品牌辅助纹理，不能作为可读正文。需要读出英文时建议双语组合宽度至少 **256px**；窄屏优先使用 `logo-full-zh.svg`，小于 96px 使用独立图标。

## HTML 内联

所有 SVG 无 XML 声明、无固定 `width` / `height` 属性，尺寸由页面 CSS 决定。文件中的根 ID 与标题 ID 均使用 `sx-` 前缀并按文件区分；单独内联图标、中文、英文时无冲突。同一资产在同一文档中重复内联时，需为每个实例追加唯一后缀，并同步修改 `aria-labelledby`；单色文件的样式选择器也应同步更新。也可用 `<img>` 重复引用。

```css
/* 按角色添加页面 class；保持纵横比。 */
.brand-mark { width: 32px; height: auto; }
.brand-zh { height: 24px; width: auto; }
.brand-en { height: 8px; width: auto; }
/* 单色默认 #F3F2F7；覆盖 SVG 本身的 color 即可。 */
#sx-logo-mono { color: #FFC24D; }
```

单色文件的路径填充 / 描边全部是 `currentColor`，默认样式只定义 SVG 的 `color` 与默认填充；也可直接在根 SVG 上加 `style="color: …"`。在父节点设色时，需同时覆盖 SVG 内的默认颜色声明。

## Do / Don't

Do：保持等比缩放、足够对比和保护区；在暗底优先用彩色版；在单色印刷或浅底环境显式设置单色 `color`；窄屏采用中文组合或图标。

Don't：不旋转最终图标、不拉宽、不重排轨道；不补成闭环、不加入中心十字线；不加发光、滤镜、渐变、额外轨道、细刻度或背景底板；不拆出星芒与轨道各自使用；不将中文定制点恢复成细小装饰。
